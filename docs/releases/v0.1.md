## 1. Overview & First User Story Delivered

Deci v0.1.0 delivers the complete **MVP (User Stories 1, 2, and 3)**:
- **US1 (Paste, Format, Grade)**: Pure client-side parsing of raw idea lists or structured AI assistant output with template validation (`decisionator.options/v1`). Instant Google Sheets creation with per-file `drive.file` OAuth scope. Option scoring (1–5) and Markdown comments with instant local autosave in IndexedDB.
- **US2 (Share & Collaborate)**: Link sharing with Drive permissions (`view` vs `contribute`), Google Picker integration, and end-to-end PBKDF2/AES-256-GCM encryption with 12+ character passphrases (`enc:v1:`). Live multi-user updates via version polling and rate-limit backoff banner with offline write queue.
- **US3 (Ranked Vote & Results)**: Top-N ranked ballot creation with keyboard and drag-and-drop `@dnd-kit` ordering. Deterministic Borda tally host with CSPRNG seed recording and multi-round state machine (`open` -> `closed` -> `reopen`). Reproducible outcome verification with one click ("Reproduced ✓").

## 3. Known Limitations & Staged-Compliance Disclosures

As established in `specs/001-decision-engine-core/plan.md`:
1. **Agentic API (MCP / REST)**: Automated agent connections and background web agent tasks are deferred to Phase 8 (User Story 5). Formatting currently uses copy-paste round-trips with general-purpose AI chat assistants.
2. **Offline Mode**: Offline capability in v0.1 is scoped to drafts and the write queue. Full standalone local-first mode without Google Drive is deferred to Phase 10 (User Story 7).
3. **Third-Party Plugin Sandbox**: Sandboxed iframe loading for external untrusted plugins is scheduled for Phase 9 (User Story 6). All built-in plugins (Google Sheets store, Borda strategy, Paste source) run in-process using the same public contracts.
